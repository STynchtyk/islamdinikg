# Islamdini

## Запуск

Нужен Node.js 18 или новее. Откройте `Start-IslamDini.cmd`: сайт откроется на `http://127.0.0.1:4175`. Для ручного запуска в папке сайта выполните:

```powershell
node server.js
```

Затем откройте `http://127.0.0.1:4173`.

Источник времени — https://www.namazvakti.com/. Сервер получает текущую страницу выбранного города, проверяет город и дату и передаёт расписание через `/api/prayer`. Дополнительный каталог Кыргызстана загружается с NamazVakti; прежние города с известными координатами сохранены. Для них NamazVakti получает запрос по координатам. При сбое используется только сохранённое расписание NamazVakti для того же города и сегодняшней даты, иначе показывается ошибка с повторной попыткой. Другие источники времени не подставляются.

Расписание обновляется при смене даты выбранного города, возвращении на вкладку, восстановлении соединения, вручную и периодически. Получается текущий день: даты будущих лет заранее не зафиксированы. Работа до 2040 года зависит от доступности и формата NamazVakti, гарантии сервиса нет. Устаревшая дата никогда не показывается как сегодняшняя.

Показаны основные столбцы NamazVakti: Fajr (имсак), Tulu, Zuhr, Asr, Maghrib, Isha. Более поздние Morning, Asr-i thani и Isha-i thani не подставляются вместо основных. Актуальный оригинал доступен на NamazVakti. При открытии `index.html` двойным щелчком загрузка времени недоступна: используйте файл запуска.

## Материалы

Интерфейс и каталог тем доступны на кыргызском, русском и английском. Поиск сопоставляет названия тем на всех трёх языках: например, «намаз» и «prayer», «орозо» и «fasting» открывают те же подборки. При переключении языка сохраняется открытая тема и статья.

Заголовки, описания и полные тексты статей автоматически переводятся с кыргызского при просмотре через внешний сервис Google Translate. При первом переводе нужен интернет; готовый перевод сохраняется в браузере (IndexedDB) для повторного чтения. При ошибке доступна повторная попытка. Автоматический перевод может содержать ошибки, особенно в религиозных терминах: кыргызский оригинал всегда доступен через меню языка. Это не профессионально проверенный перевод. Публичный текст статьи передаётся внешнему сервису только при выборе русского или английского языка.

В `public/data/materials.json` добавлены публичные статьи из переданной резервной копии. На сайте они сначала показаны как современный каталог тематических папок: посетитель выбирает тему и только затем видит связанные с ней материалы. Поиск работает по названиям тем, а для частых вариантов вроде «намаз», «орозо», «оризо» и «пост» подбирает только соответствующие папки, а не случайные упоминания в полном тексте. Исходный архив посетителю не показывается.

Во время сборки рядом автоматически создаётся `public/data/materials.js`. Благодаря ему готовый `index.html` можно открыть двойным кликом как обычный файл: каталог материалов не зависит от `fetch` и не требует локального сервера.

Для повторного импорта SQL-резервной копии используйте:

```powershell
node scripts/import-legacy-materials.mjs <source.sql> public/data/materials.json
```

Импортёр читает только публичные записи `dle_post` и названия категорий из `dle_category`; учётные записи, журналы, настройки и другие таблицы не переносятся. HTML из старых записей очищается до текста перед публикацией.
