ПОЛНЫЙ САЙТ ДЛЯ NETLIFY

Не перетаскивайте эту папку в Netlify Drop для полного запуска:
серверные функции времени намаза необходимо собрать и опубликовать вместе с сайтом.

Рекомендуемый способ:
1. Загрузите содержимое этой папки в один Git-репозиторий с сохранением структуры.
   В корне должны находиться index.html, translation.js и netlify.toml.
2. Подключите этот репозиторий в настройках СУЩЕСТВУЮЩЕГО сайта islamdini в Netlify.
3. Base directory — пусто, если файлы находятся в корне репозитория.
   Build command: node scripts/build-vercel.cjs
   Publish directory: dist
   Functions directory: netlify/functions
4. Выполните новый Deploy. Файл netlify.toml уже содержит эти настройки.

Альтернатива через установленный официальный Netlify CLI:
Откройте терминал в этой папке.
netlify login
netlify link
Выберите существующий сайт islamdini, а не создавайте новый.
netlify deploy --build --prod

После публикации проверьте главную страницу, Намаз, Дуба, Китепкана, Медиа, Видео и время намаза.
Время приходит с NamazVakti и зависит от доступности источника.
Эта папка подготовлена локально. Она не обновляет Netlify автоматически.
